# Agent skills

Task playbooks for coding agents working on this repository (Agent Skills format: one folder
per skill with a `SKILL.md`). They are written in Spanish for the owner; repository artifacts
they produce (code, docs, commits) stay in English per `AGENTS.md`.

| Skill | Use it when |
|---|---|
| `ra-dev-session` | starting, implementing, committing and handing off any change |
| `ra-phase-gate-review` | deciding whether a phase F0–F12 can pass its gate |
| `ra-nemotron-token-factory` | planner/prompt/model changes, live spikes, budget report |
| `ra-safe-action` | adding a remediation action or a UVC/ONVIF device adapter |
| `ra-vision-probe` | new probes or fault rules, threshold calibration, false positives |
| `ra-fault-benchmark` | datasets, fault injection manifests, metrics, ablations (F4/F10) |
| `ra-hackathon-submission` | rules compliance, demo video, Devpost text, final tag (F12) |
