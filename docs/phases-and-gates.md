# Phases and exit gates

Source of truth: [`docs/es/informe-tecnico-ejecucion.md`](es/informe-tecnico-ejecucion.md) (Spanish technical report).
This file is the operational checklist. **A phase passes only when every box is ticked and each
tick links to evidence generated by CI, a benchmark report or a run log** — never because "the demo
looks like it works".

Transition rule (all required simultaneously): integrated code · green tests · metrics above
threshold · reproducible artifact · review by a *different* agent · residual risks documented.

Thresholds are initial internal targets, configured in `configs/default.yaml`, and must be
recalibrated with real camera data.

live Token Factory calls or human reviewers stay open until that evidence exists.

- Alert flapping vs frame-by-frame detector: ≥ 50% reduction on noisy synthetic sequences

- 5 MVP faults reach CONFIRMED (`test_mvp_faults_reach_confirmed`); 4 recoverable synthetic
  scenarios commit and a harmful action is rolled back (`tests/e2e/test_scenarios.py`).
